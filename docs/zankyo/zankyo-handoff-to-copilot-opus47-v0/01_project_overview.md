# 01. Project Overview

## 名前

残響座標

## 一文定義

残響座標は、ユーザーが自分で持っているReol音源をローカルで読み込み、既存ファンサイト由来のセトリ・曲マスタ・会場情報と照合し、「あの日の会場・立ち位置・音響・余韻」を重ねて再生するスマホファーストWebプレイヤーです。

## これは何ではないか

- 音楽配信サービスではない
- 汎用音楽プレイヤーではない
- 歌詞表示アプリではない
- ジャケット閲覧アプリではない
- SNS投稿支援ツールではない
- 動画生成ツールではない
- 公式アプリではない
- デモ体験サービスではない

## 中核思想

```txt
アプリは器。
音源はユーザーの手元。
記憶はユーザーの中。
ファンサイトは曲・セトリ・会場の骨格を渡す。
残響座標はそこに音響と残光を重ねる。
```

## 全体レイヤー

```txt
既存Reolファンサイト
  ↓
static/data/live.json
static/data/discography.json
  ↓
Gatsby build-time transform
  ↓
static/zankyo/generated/
  tracks / setlists / venues / venue-layouts
  ↓
/zankyo/
  ↓
ユーザーのローカル音源選択
  ↓
セトリ充足チェック
  ↓
再生 / Web Audio / Canvas残光アート
  ↓
公演記憶として保存
```

## 最初に作るべきもの

今はまだプレイヤー本体よりも、Gatsbyビルド時データ変換を優先する。

理由:

- セトリ・曲マスタ・会場データが安定しないと、プレイヤーが作りにくい
- 既存ファンサイトのデータを正式に残響座標用JSONへ変換する層が必要
- 後続のセトリ充足チェック、会場レイアウト、立ち位置UIの土台になる
