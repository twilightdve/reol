# 08. UI / UX Mobile First

## UI思想

サービスではなく、私設の再生室。  
説明しすぎない。  
音源を持つ人だけが入る。  
でも迷わせない。

## 基本画面

### Home

```txt
残響座標

音源は含まれていません。
選択した音源はアップロードされません。

[ 音源フォルダを選ぶ ]
```

デモなし。  
チュートリアルなし。  
必要最小限の説明だけ。

### Library

- 読み込んだ音源一覧
- アルバム/フォルダ単位
- 拡張子表示
- 読めないファイルの警告
- 再スキャン

### Setlists

- セトリ一覧
- 充足チェック
- 候補手動紐付け
- セトリ再生へ進む

### Player

スマホ縦画面。

```txt
[Canvas 残光アート]

曲名 小さく
再生/停止
シークバー
前/次
立ち位置ミニマップ
```

通常時はUI最小。  
タップでUI表示/非表示。  
長押しは誤操作防止のため、重要操作にだけ使う。

### Memory

- 会場タイプ
- 立ち位置
- 位置ラベル
- 無言タグ
- 公演記憶保存
- 終演後モード履歴

## ジェスチャー

v0では控えめにする。

- タップ: UI表示/非表示
- 左右スワイプ: 前/次曲は誤操作が怖いので後回し
- 立ち位置マップ上のドラッグ: 位置変更
- 長押し: 記憶保存など確認あり

## スマホ負荷

- battery_saver
- standard
- high_visual

UI上は「軽量」「標準」「濃い」などでもよい。

## 初回体験

```txt
Home
  ↓
音源フォルダ選択
  ↓
Library scan
  ↓
セトリ選択
  ↓
充足チェック
  ↓
Player
```

## 音声開始

ブラウザの自動再生制約を前提に、ユーザー操作で開始。

```txt
TOUCH TO START
```

これは制約ではなく「開場」の儀式として扱う。

## エラー表示

冷たすぎないが、過剰にサービスっぽくしない。

例:

```txt
この形式はこのブラウザでは再生できません。
別形式の音源を選んでください。
```

```txt
この曲は候補が複数あります。
使う音源を選んでください。
```

```txt
重いため軽量モードに切り替えました。
```
