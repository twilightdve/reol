# 01. Product Requirement

## プロダクト名

残響座標  
英語サブタイトル案: Reol Local Afterglow Player

## コンセプト

残響座標は、ユーザー自身が持つローカル音源を使って、ライブ体験の「聴こえ方」と「余韻」を再構成するWebプレイヤーである。

普通の音楽プレイヤーは「曲」を再生する。  
残響座標は「曲 + 公演 + 会場 + 立ち位置 + 音響 + 余韻」を再生する。

## 対象ユーザー

- Reolのライブ体験を自分の中で再点火したい人
- 自分で音源を持っている人
- スマホでローカル音源を再生しながら、視覚・空間・余韻を重ねたい人
- 丁寧なチュートリアルやデモがなくても使える人

## 非対象ユーザー

- 音源を持っていない人
- 音楽配信サービスを期待する人
- SNS用動画を書き出したい人
- 歌詞やジャケットを見たい人
- 公式アプリや公式コンテンツを期待する人

## 必須方針

- 公開Webアプリだが、サービスっぽくしない
- デモモードなし
- 共有機能なし
- 投稿支援なし
- 音源提供なし
- ローカル完結
- スマホファースト
- 使いたい人だけが使う設計

## 主要機能

1. ローカル音源ライブラリ
2. セトリ充足チェック
3. セトリ再生
4. 会場タイププリセット
5. 立ち位置マップ
6. 音響再構成
7. Canvas残光アート
8. 曲後の残光時間
9. 終演後モード
10. 無言タグ
11. 公演記憶アーカイブ
12. PWA/オフライン
13. Media Session/Wake Lock/軽量モード

## 除外機能

- 音源アップロード
- 音源配信
- 歌詞表示
- ジャケット画像取得
- 公式ロゴ使用
- ライブ映像再現
- SNS切り抜きモード
- 投稿用動画生成
- 共有リンク
- デモモード
- ユーザー獲得向けチュートリアル

## 成功条件

- ユーザーがローカル音源フォルダを選ぶだけでライブラリができる
- セトリに対する音源充足状況が分かる
- セトリ再生ができる
- 音に応じて残光アートが気持ちよく動く
- 会場タイプと立ち位置で聴こえ方/見え方が変わる
- 曲後に余韻が残る
- 全てローカルで完結することがUI上も実装上も明確
