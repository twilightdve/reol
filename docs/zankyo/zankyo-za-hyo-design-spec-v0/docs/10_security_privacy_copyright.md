# 10. Security / Privacy / Copyright Policy

## ローカル完結

アプリは音源をサーバーへ送らない。  
音源はユーザーが選択した端末内ファイルのみ。  
再生・解析はブラウザ内で完結する。

## トップ画面表示

```txt
音源は含まれていません。
選択した音源はアップロードされません。
権利を持つ、または適法に利用できる音源のみを使用してください。
```

## 禁止する実装

- 音源アップロード
- 音源配信
- 音源共有
- 歌詞取得・表示
- ジャケット画像取得
- 公式ロゴ使用
- ライブ映像再現
- SNS投稿用動画生成
- 共有リンク生成
- 外部解析送信

## Analytics

v0ではなし。  
`analyticsEnabled: false` 固定。

収集しない:

- ファイル名
- 曲名
- アーティスト名
- フォルダパス
- 音源メタデータ
- 再生履歴
- 公演記憶
- 立ち位置

## 権利方針

このアプリは音源を提供しない。  
ユーザー自身が用意した音源をブラウザ内で再生するための器である。

公開時の注意文:

```txt
Unofficial fan-made local player.
No music files included.
No upload.
No streaming.
```

## 公式誤認防止

アプリ名に「Official」「Reol公式」等を使わない。  
ロゴ、写真、ジャケット等の公式素材を使わない。  
説明文では非公式であることを明記する。

## ファイルアクセスの安全

- ユーザーが選んだファイルだけ読む
- 選択されていないローカルファイルにはアクセスしない
- `webkitdirectory` 使用時も選択フォルダ内だけ
- FileSystem Access APIへの依存はv0では避ける

## 出力の安全

SNS切り抜き、動画書き出し、音声書き出しは作らない。  
鑑賞モードはUI非表示のみで、出力機能ではない。
