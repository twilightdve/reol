— ミュータント

在最前排沉浸於感性的歌曲，同時獨自不斷探索歌詞與 MV 的深層意義。以獨到詮釋潛入音樂深淵的孤獨探究者。

獨自進化的存在

不滿足於既有的詮釋，為了找出只屬於自己的答案，反覆重讀歌詞，把 MV 的一個鏡頭重播幾十次。

孤獨的探究之路

不會主動分享自己的考察，因為還在探究途中。不喜歡發表半吊子的詮釋，會一直思考直到想通為止。

持續變異的感性

半年後再聽同一首歌，有時會發現完全不同的意義。能享受音樂與自己的關係不斷「突變」，正是其強項。
