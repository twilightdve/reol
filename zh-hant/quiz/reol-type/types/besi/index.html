— 極彩色

把在後方直覺感受到的東西，以自己獨特而鮮明的表現傳達給周圍。擁有插畫、詩、粉絲創作等超越言語的表現力。

擁有鮮明感性的人

在16種類型中以最獨創的方式表現 Reol 的音樂。畫插畫、寫成詩——擁有不只依賴言語的多彩表現力。

來自後方的輸入

身在後方，能把燈光營造出的全場色彩、觀眾剪影之美、舞台與觀眾席合為一體瞬間的全景——這些創作素材烙印在心中。

分享的喜悅

只要發一張「那場演唱會就是這種感覺」的插畫，就能瞬間傳達言語無法完全表達的現場氛圍。
