### 2-2. CLS(レイアウトのずれ)

- **HOME・DISCOGRAPHY・`/en/`**: Lighthouse は毎回フッターを「ずれた要素」に挙げる(0.289。`/en/` は 0.368)。原因は、節に `content-visibility: auto` を付けていて、高さの見積もり(`contain-intrinsic-size`)が無いこと。最初の一瞬だけ節の高さが 0 になり、フッターがヘッダーのすぐ下に来て、次の瞬間に下へ動く。配る HTML からこの指定を抜いて測り直すと、3 ページとも 0.29 → 0.00(`/en/` は 0.405 → 0.037)になった。指定があるのは `HomeSection.tsx:164` と `DiscographySection.tsx:28` の 2 か所で、ずれが出るページと一致する。
  - このずれは読み込みから 30〜60ms、最初の描画より前に起きる。Lighthouse のコマ送りの写真には写っていない。**実際の利用者の CLS に数えられているかは未確認**(フィールドデータが無い)。Lighthouse の点には確実に効いている(HOME 81 → 推測で 90 台)。
- **公演ページ `/live/toukyou-10/` 0.122**: 読み込みから約 3.2 秒後(絞った環境)、`section.mb-10` が y 420 → 666 に下がる。上に約 246px の塊が後から入る。これは描画の後なので、利用者にも見えるずれ。どの部品かは未確認。
- **曲ページ `/songs/no-title/` 0.042**、**`/en/` の残り 0.037**(動画の帯が高さ 141 → 0 になり下の節が動く): 「良い」の線 0.1 の内側。
- どのページでも、ヘッダー右の並び(検索・言語・テーマ)が 36px 横に動く(0.0004。人のアイコンが後から増えるため。コマ送りの写真で確認)。点には効かない。
