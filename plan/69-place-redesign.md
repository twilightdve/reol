## 1. 直す前に見えていたこと

作り直す前の画面(Chromium、幅390と1280)を撮って確かめたもの。

| 場所 | 困る点 |
|------|--------|
| 地図 | Leaflet 既定の青い画像ピンが東京に重なって読めない。画面の幅いっぱい・高さ60vhで、スマホでは1本指のスクロールが地図に取られて下へ進めない。拡大ボタンが端で切れる。著作権表示が2つ出る |
| 地図と一覧 | つながっていない。ピンを押しても一覧のどこか分からず、一覧から地図の位置へも行けない |
| 絞り込み | 上に貼り付く帯が2段+件数で高く、開いたカードに重なる |
| 作品カード | `role="button"` の div の中にボタンが入れ子。題名が1行で切れる。サムネイルの上下に黒帯 |
| スポット | 地図タイル1枚(ピンなし・中心ずれ)の小さな絵。バッジが淡いパステルで、ほかの画面の色と合わない |
| 全体 | 広い画面で幅が余る。見出しの字間が広く、文字が重い |

## 2. 決めたこと

- **地図と一覧を行き来できるようにする。** ピンを押すと地図の上にカード(作品・スポット名・住所)が出て、「一覧で見る」でその行へ動く(作品が閉じていれば開く)。一覧の「地図で見る」で、地図がそのスポットへ寄る。スマホでは地図まで画面を戻す。「全体を表示」で元の範囲へ
- **ピンはサイトの色の丸。** 黄 = まだ、青 = 巡礼済み。選んでいるピンは大きくして輪を付ける。巡礼済みが1つでもあれば、地図の下に凡例を出す
- **指で操作する端末では、1本指は画面のスクロール。** 地図は2本指で動かす・広げる(左下に一言)。マウスの端末はこれまでどおりドラッグ
- **広い画面は2段。** 左に一覧、右に地図(スクロールに付いてくる)。スマホは 地図 → 検索 → 一覧 の縦並び。地図は枠の中に収め、全幅表示をやめる
- **見出し。** 数字3つ(作品・スポット・都道府県。データから数える)、渋谷編ガイドへの入口をカードに、スタンプ帳に進み具合の棒。導入文の言葉は変えていない
- **絞り込み。** 上に残すのはタイプの1行だけ(各タイプの件数つき。はみ出す分は横に送る)。検索と「タイプ別／都道府県別」は貼り付けない
- **作品カード。** 開閉は本物の `button`(`aria-expanded`・`aria-controls`)。巡礼済みの✓は別のボタン。題名は2行まで。サムネイルは 16:9(`mqdefault`)
- **スポットの行。** 番号(タイプ別)またはピンの印(都道府県別)、名前、要費用・要許可、住所、メモ、「地図で見る」「Google Maps」「Webサイト」。タイル1枚の小さな地図はやめた(ページの中の地図へ寄る方が位置が分かる)
- **`#place-<slug>` で来た時は、その作品を開いておく**(サイト内検索の結果から来た時)

変えていないもの: データ、URL の `?type=`・`?view=`・`?q=`、スタンプ帳の保存先(この端末のブラウザ)、計測イベント(`place_guide_click`、絞り込み)。足した計測イベントは `place_show_on_map`・`place_show_in_list`(ラベルはスポットの slug)。

## 3. 一緒に直した不具合

| 不具合 | 直し |
|--------|------|
| WebKit の暗いテーマで、地図の左に黒い帯が残る(タイルは読み込めているのに描かれない)。地図を最初の位置から動かした後に、新しく見えた部分が描かれない | 暗くするフィルタを、タイルの層ではなくタイル1枚ずつに掛ける。LIVE の開催地マップ(`/live/heatmap/`)も同じ指定を使っているので、同じく変わる(見た目は同じ) |
| 都道府県の取り出しが「都・道・府・県」の最初の1文字で切る書き方で、「京都府」は「京都」になる(いまのデータに京都府は無いので、表には出ていなかった) | 都道府県名の一覧と照らす |

## 6. 追記(2026-11-13): 動画と地図の埋め込み、色と文字の見直し

運営者の指摘「YouTube埋め込みや地図埋め込みはできるはずなのになぜしないの？」と、「デザインする上でこのスキルを参考にして」(unslop)を受けて直した。コミット `57e3693de39`(読みものへの移動 plan/70 と同じコミット)。

### 6-1. 埋め込み

それまで外部へのリンクだけだった理由は、一覧に何十も iframe を並べると重くなるのを避けたためで、できないからではなかった。置き方を工夫して入れた。

| もの | 置き方 |
|------|--------|
| Google マップ(スポットの詳細、ガイドの各場所) | `src/components/common/MapEmbed.tsx`。枠の大きさを先に取り、iframe は画面の近く(上下 800px)にある間だけ置く。離れたら外す。キーの要らない埋め込み用 URL を使う |
| YouTube(MV など) | 記事と同じ「押してから再生」の部品(`PlayerSlot`)。押すまで動画のプレイヤーは読み込まない |
| ガイドの「歩いて回る」 | 番号つきのピンの地図(`src/components/place/ShibuyaRouteMap.tsx`、OpenStreetMap)。番号を押すとその場所の説明へ。点線は順番の目安で道順ではない(本文にもそう書いた)。JS が動かない時は、前からある略図のまま |

### 6-2. 色と文字(unslop の指針を参考に)

配色(黒×公式の青×黄)は変えず、使い方を整えた。

- 黄は「選ばれているもの」と主な操作だけ、青は「巡礼済み」だけ、ほかは無彩色に揃えた(順路の点線も無彩色)
- グラデーション・光彩・絵文字のアイコンは足していない
- 11px より小さい文字を無くした(地図の出典表記を含む)
- サイト全体で決まっている部品(小見出しの `Kicker`、巡礼済みの丸、h2 の太さ)は、このページだけ変えることはしていない

参考にしたもの: unslop(Damir Sokolovsky @heydamir、<https://github.com/heydamir/unslop>、CC BY 4.0)。文面や部品を写してはいない。
