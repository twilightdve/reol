# 4. 訴求力改善(文言案)

トーンの原則: 現状のABOUT文(誠実・等身大)を活かしつつ、「間違いがあるかも」系の免責はmetaから外してABOUT内に置く。過度に広告っぽくせず、Reolの世界観、インターネット出身の文脈、ライブの熱量、データを掘る楽しさ、ファン同士の共鳴が伝わるものにする。
