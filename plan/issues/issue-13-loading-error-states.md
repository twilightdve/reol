# 【P2】ローディング/エラー/オフライン状態の全サイト共通化

## 背景

非同期データ取得を行うページ(セトリ予想、参加者一覧、統計、検索など)のローディング/エラー表現がページごとにバラバラ、またはエラーUIが存在しない(推測)。PWA(gatsby-plugin-offline)なのでオフライン時の挙動も重要。

## 現状の問題

- `/bijigaku-navi/setlist-prediction` 等が「読み込み中...」テキストのまま(実確認済み)
- フェッチ失敗時に再試行手段がない(推測)
- オフライン時の案内がない

## 期待する挙動

- ロード中: 統一スケルトンUI
- 失敗時: エラーメッセージ+再試行ボタン
- オフライン時: 「オフラインです。閲覧できるのはキャッシュ済みページのみです」等の案内

## 実装方針

1. Issue 4 で作る `LoadingSkeleton` / `ErrorRetry` を共通コンポーネント化(`src/components/common/`、既存 `EmptyState.tsx` を拡張)
2. 非同期取得ページ(setlist-prediction、attendance系、search、stats)に順次適用
3. `data_load_error` GA4イベントで失敗率を計測

## 影響範囲

非同期データ取得を行う全ページ・コンポーネント。

## 受け入れ条件

- [ ] 対象ページ全てでスケルトン→成功/エラーの3状態が表示される
- [ ] エラー時に再試行できる
- [ ] `data_load_error` が計測される

## 確認方法

DevToolsのネットワークブロック/オフラインシミュレーションで各ページ確認。

## 優先度 / 見積もり難易度

P2 / 中(2〜3日)
