# 【P1】「はじめてのReol」ページ新設

## 背景

新規リスナー向けの静的な入口ページが存在せず、「Reol おすすめ曲」「Reol 入門」等の検索需要を取れていない。トップの入口3カード(Issue 7)の遷移先としても必要。

## 現状の問題

新規がサイトに来ても、どこから掘ればいいかのガイドがない。ABOUTはダイアログ内、コンテンツはDB的一覧のみ。

## 期待する挙動

`/welcome/`(パスは要検討)に:

- 年代別の代表曲紹介(公式YouTube埋め込み)
- 「次に聴くなら」の分岐(ゴリゴリ系/エモ系など、診断の軸を流用)
- ファンタイプ診断・楽曲統計・LIVEへの内部リンク
- 公式サイト・配信への送客CTA

## 実装方針

1. 静的ページとして `src/pages/welcome.tsx` を新設(ビルド時生成、JSなしで全文読める)
2. 埋め込みは公式YouTubeのみ使用(権利方針の遵守)
3. 公式リンクに `official_link_click` イベント
4. SEO: title「はじめてのReol - 入門ガイド」、個別description、Article + BreadcrumbList のJSON-LD

## 影響範囲

新規ページ、トップの入口カード、ヘッダー/フッターのリンク。

## 受け入れ条件

- [ ] JSなしで全文が読める
- [ ] 公式リンクにイベント計測がある
- [ ] モバイルで埋め込み動画が崩れない

## 確認方法

curl でHTML確認、実機表示確認、GA4 DebugView。

## 優先度 / 見積もり難易度

P1 / 中(2〜3日、選曲・執筆含む)
