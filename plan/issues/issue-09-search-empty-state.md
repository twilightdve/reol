# 【P1】検索ページの初期0件表示と空状態改善

## 背景

`/search` は楽曲・アルバム・LIVE・ロケ地の横断検索で、サイトのDB性を象徴する機能。

## 現状の問題

- データロード完了まで、フィルタタブが「すべて(0) 楽曲(0) アルバム(0) LIVE(0) ロケ地(0)」と表示される(実確認済み)。「データがないサイト」という第一印象を与える
- 「データを読み込み中…」表示はあるが、空状態のガイド(何を検索できるか)がない

## 期待する挙動

- ロード中は件数を非表示にし、スケルトンを表示
- 空状態(未入力時)に「例: 第六感 / Zepp / MVロケ地」などのサンプルクエリチップを表示
- 0件ヒット時は「もしかして」+主要コンテンツへのリンク

## 実装方針

1. `src/pages/search.tsx` のタブ件数を `isLoading ? null : count` に変更
2. 空状態コンポーネント(サンプルクエリチップ)を追加。チップクリックで検索実行
3. `search_query` GA4イベント(0件クエリも記録し、コンテンツ需要調査に転用)

## 影響範囲

`src/pages/search.tsx`。

## 受け入れ条件

- [ ] 初期表示に「(0)」が出ない
- [ ] サンプルクエリから検索を実行できる
- [ ] 0件時にガイドが表示される

## 確認方法

低速回線シミュレーションで初期表示確認、0件クエリ入力で確認。

## 優先度 / 見積もり難易度

P1 / 低(半日〜1日)
