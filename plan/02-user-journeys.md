# 2. ユーザー別の理想導線

| ユーザー | 最初に見るページ | 次に誘導 | 最後の行動 | 必要な改善 |
|---|---|---|---|---|
| Reolを最近知った人 | トップの「はじめてのReol」ブロック(新設) | 年代別入門/代表曲→公式MV埋め込み | 公式YouTube登録・配信で聴く | ファーストビューに新規向けCTA。現状はABOUTがダイアログ内で、新規は何のサイトか分からない |
| 有名曲だけ知っている人 | 楽曲ページ(その曲の演奏履歴・統計) | 「この曲が演奏されたライブのセトリ」→隣の曲 | 知らなかった曲を公式で聴く | 楽曲統計の各行から曲詳細→セトリ→公式動画へのリンク連鎖。現状statsは一覧表止まり |
| ライブに初めて行く人 | ライブ初参加ガイド(新設。checklist資産を転用) | 該当公演の会場ページ(美辞学ナビ資産) | チケット購入(公式リンク) | 「初参加ガイド」をLIVEページ上部に常設。チケット導線の明示 |
| ライブ遠征をする人 | 会場ページ(アクセス・周辺情報) | PLACE(近隣の聖地)・参戦地マップ | 遠征計画を立てX共有 | 会場ページ⇔PLACEの相互リンク(同一都道府県で自動接続) |
| セトリを予想したい人 | セトリ予想 | 楽曲統計(演奏回数・最終演奏日で根拠づけ) | 予想を投票しX共有 | 予想ページに統計へのリンク、予想結果のOGP付き共有URL |
| 武道館等の余韻を掘りたい人 | 該当ライブのセトリページ | セトリ各曲→公式動画、関連ポスト、PHOTO | 「余韻プレイリスト」的にYouTube公式へ | ライブ詳細に「このライブを追体験」ブロック(公式動画への安全なリンク集) |
| 古参ファン | 楽曲統計・TIMELINE | 相関図・歌ってみた一覧・初期曲の演奏履歴 | 発見をX共有、リクエストを送る | 統計に「初出が古い順」「◯年演奏なし」等のソート軸追加 |
| SNSで布教したい人 | ファンタイプ診断 | タイプ別おすすめ曲→公式動画 | 診断カードをX共有 | 診断結果ページのOGPをタイプ別画像に。共有文言に代表曲を含める |
| 海外ファン | EN版トップ(現状ほぼ未対応) | Discography/Live(固有名詞は英併記) | 公式YouTube/国際配信リンク | まずは `<html lang>` とhreflang、主要ページの英語要約。Manga Barcelona 2026出演が載る今は好機 |
