# 52. 読みもの一覧をカード型に

2026-10-23 ユーザー「記事一覧のデザインを変更したい 記事の表紙デザインを反映させたカード型のアイテムにしたい」。

- 一覧の各記事をカードに。上に記事の表紙の画像(40:21)、下に曲名・題名・要約(3行まで)・日付・表示回数・いいね・タグ。カード全体(タグ以外)が記事へのリンク。
- 並び: スマートフォン 1列、640px〜 2列、1024px〜 3列。一覧の幅を max-w-3xl → max-w-5xl に広げ、見出しと説明文は max-w-3xl のまま。
- 表紙の画像: `npm run articles:og` が OGP 画像と同じ表紙から `static/articles-cover/<slug>.jpg`(800x420、右下のサイト名なし、mozjpeg 82)も書き出す。リポジトリにコミット。無い記事は曲名だけの無地のカード。
  - 画像は表紙のスクリーンショットで、公式のジャケット・MV のサムネイルは含まない(OGP と同じく capture-article-og.ts が隠す)。
  - 表紙のデザインを変えたら OGP と一緒に撮り直す(同じコマンド)。
- 確認: 開発サーバーの Chromium・WebKit、360・768・1280px。横はみ出しなし、エラーなし、画像14枚が読み込まれる(360px は遅延読み込みのため画面外は後から)。
