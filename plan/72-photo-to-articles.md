## 手順

### 楽曲記事(変更なし)

`npm run articles:import` → 記事別デザイン → `npm run articles:preview` → `npm run articles:publish -- --id … --revision N` → `npm run articles:og` → コミット → デプロイ。

### 記録

1. 雛形を作る: `npm run articles:photo -- generate --group <まとまりのID> --write`(`.articles-local/records/<記事ID>/` に `body.md`・`media.json`・`meta.json`)
2. 写真を見て代替テキストを書く。関連リンクの見出しを直す。表紙にする写真を選ぶ
3. 取込: `npm run articles:record -- --id <記事ID>`(検査だけなら `--check`)
4. 台帳の検査: `npm run articles:photo -- check`
5. プレビュー: `npm run articles:preview`
6. `.articles-local/staging/<記事ID>/editorial.json` で slug を決め、`slugProposed` を `false` に
7. 公開: `npm run articles:publish -- --id <記事ID> --revision N`(`--unlisted`・`--at` も楽曲記事と同じ)
8. コミット → 頼まれた時にデプロイ

### 聞かずに決めたこと(下書きの分)

| 決めたこと | 理由 |

| 見出しの順は古い順(例: 北海道1日目 → 2日目 → 公演 → 3日目) | 旧 PHOTO は新しい順に並んでいるが、1本の記事として読むなら出来事の順のほうが追いやすい。文章は変えていない。先行2本は見てもらった順のまま |
