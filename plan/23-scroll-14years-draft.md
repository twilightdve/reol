# 案D「スクロールで読む◯年」— 骨子・ドラフト版

新規コンテンツ案D(`plan/legit-improvement-plan.md` 5章)の設計骨子と本文ドラフト。
フェーズ5の中で唯一「新規執筆が必要」とされていた案。

**このドキュメントの位置づけ**: 本文は**ドラフト(叩き台)**。事実関係はインタビュー等の
一次情報で裏取りしているが、「どう語るか」はユーザーの監修を前提とする。
実装(スクロール連動の作り込み)は本ドラフトの承認後に着手する。

---

## 1. 何を解決する企画か

現在の `/welcome/` は代表曲リスト中心で、**名義の変遷の文脈がほぼ説明されていない**。

- れをる → REOL → Reol という3つの名義は、新規リスナーが最も混乱し、かつ最も知りたい部分
- 「REOL」と「Reol」は表記が1文字違いなのに**別体制**(3人組ユニット / ソロ)
- 現行 `/welcome/` の era 区切りは 2012–2016 / 2017–2019 / 2020–2022 / 2023– という
  **均等割りで、名義の切れ目と一致していない**

本案は `/welcome/` を「曲リスト」から「一本の物語」に再構成し、
スクロールに沿って**名義の変遷=Reolの14年**を読ませる。

## 2. 先に決めた制約(実装時に必ず守る)

### 2-1. 著作権 — 本文にインタビューの引用を含めない

本ドラフトの事実関係はインタビュー記事を典拠にしているが、**記事本文の引用・要約転載は行わない**。

- 本人の発言を「」で括った引用は**本文に一切置かない**
  (二次要約を経た文言は逐語性が保証できず、実在の人物に不正確な発言を帰属させるリスクがある)
- 事実・出来事は**すべて自分の言葉の地の文**で書く
- 出典は**外部リンクとして提示**し、詳細は公式・媒体側で読んでもらう
  (サイト既存の `reports` / `report_click` 送客パターンと同じ思想)

> サイトの基本方針「節度ある引用」「公式コンテンツへの送客を優先」に沿う。

### 2-2. 年数・数値をハードコードしない

- タイトルの「14年」は `2026 − 2012` の計算結果。**来年には15年になる**
- `src/constants/artist.ts` に `ACTIVITY_START_YEAR = 2012` と `activityYears()` が既にある。
  本文中の年数は**必ずこれを使って動的に描画する**
- 本ドラフト内で **`{活動年数}`** と書いた箇所は `activityYears()` の埋め込み位置
- 累計値(楽曲数・公演数)も同様にビルド時データから注入し、原稿に直書きしない

### 2-3. SSG制約

- 本サイトはGatsbyでSSG、GitHub Pagesホスト。**SSRは不可**
- スクロール連動の出現・配色変化は**クライアント側のみ**(`IntersectionObserver`)。
  既存の `LazyYoutube.tsx` と同じ方式
- **`prefers-reduced-motion` を尊重する**。既存の `src/hooks/useReducedMotion.ts` を使い、
  縮小動作時はアニメーションなしで全文を即時表示する(`mainVideo.tsx` に前例あり)
- 本文はSSRのHTMLに含める(SEO・非JS環境で読める状態を維持)。
  スクロールで制御するのは**演出のみ**で、コンテンツの出し分けには使わない

## 3. 骨子 — 3章構成(名義=章)

現行 `welcome.tsx` の `ERAS` 定数(4分割)を**廃し、名義に一致する3章**に置き換える。
これは既存ページのデータモデル変更を伴う。

| 章 | 名義 | 期間 | 配色の方向性 | 章のテーマ |
|---|---|---|---|---|
| 1 | **れをる** | 2012–2015 | モノクロ〜寒色(顔が見えない=声だけの存在) | 声だけで始まった / 3人が集まる |
| 2 | **REOL** | 2016–2017 | 高彩度・原色(ユニットの攻撃性) | 3人がREOLと名乗った1年半 |
| 3 | **Reol** | 2018– | サイト標準の黒×青×黄へ収束 | ひとりで引き受ける |

**なぜ3章か**: 名義の切れ目がそのまま体制の切れ目であり、
「表記が似ているのに別物」という新規リスナーの最大の混乱点に直接答えるため。

### スクロール体験の流れ

```
[導入] 3つの名前があります —— という問いかけ
   ↓
[第1章 れをる 2012-2015]  配色: モノクロ寄り
   ・節目カード: 極彩色 (2015-07-29) / 初ワンマン (2015-10-23)
   ・データ挿入①
   ↓ 章間で配色が切り替わる
[第2章 REOL 2016-2017]   配色: 高彩度
   ・節目カード: Σ (2016-10-19) / 終楽章 (2017-10-22)
   ・データ挿入②
   ↓
[第3章 Reol 2018-]       配色: サイト標準へ
   ・節目カード: 虚構集 / 事実上 / 金字塔 / 第六感 / BLACK BOX
   ・節目カード: 武道館 (2024-08-17) / 横浜アリーナ (2025-11-09) / 美辞学
   ・データ挿入③
   ↓
[着地] 現在地 → サイト内DBへの入口(統計・セトリ・相関図・タイムマシン)
```

### 節目カードの中身

各節目で「公式MV埋め込み(あれば)」+「1〜2文の説明」+「サイト内の該当ページへのリンク」。
MVは既存の**ファサード方式**(サムネイル+再生ボタン、タップまでiframeを差し込まない)を踏襲する。

### 第1章 — れをる(2012–2015):声だけが、そこにあった

はじまりはニコニコ動画だった。
2012年、**れをる**名義で歌ってみたを投稿しはじめる。

当時、顔も年齢も公開していない。
リスナーの前にあったのは声だけで、
それ以外の情報は意図的に置かれていなかった。
([出典: 金字塔インタビュー / Real Sound](https://realsound.jp/2020/01/post-489912.html))

そして本人は当時、**前に出ることを戦略的に選んでいなかった**。
サウンドクリエイター・ギガの音楽を世に届けることが先にあり、
自分はその歌い手として立つ——という役割分担だった。
パーソナルな部分は、あえて見せない。
([出典: 『虚構集』オフィシャルインタビュー / JVCケンウッド・ビクターエンタテインメント](http://www.jvcmusic.co.jp/reol/interview/))

- **2013-09-23 初のライブ出演** — 東京ニッショーホール(イベント出演)

**そして2014年、のちのREOLになる3人が、すでに揃う。**

サウンドクリエイターの**ギガ**、映像クリエイターの**お菊**との3人で、
自主制作アルバム『No title+/-』を出している。名義は「あにょすぺにょすゃゃ」。
([出典: Wikipedia](https://ja.wikipedia.org/wiki/%E3%82%8C%E3%82%92%E3%82%8B))

- **2014-08-17『No title-』** — あにょすぺにょすゃゃ名義
  (このアルバムは10年後の2024年にアナログ盤として再発される)
- **2015-07-29『極彩色』** — れをる名義のアルバム
- **2015-10-23 初のワンマン公演** — TSUTAYA O-EAST「極彩色HighFidelity」

> 初ワンマンの時点で、投稿・リリースは累計47作。
> ステージに立ったのは、まだ7回だった。

### 第2章 — REOL(2016–2017):3人がREOLと名乗った1年半

**2016年3月**、その3人が**REOL**というユニット名を得る。
表記が大文字になり、体制が正式なものになった。
([出典: Wikipedia](https://ja.wikipedia.org/wiki/%E3%82%8C%E3%82%92%E3%82%8B))

- **2016-10-19『Σ』** — REOL名義の1stアルバム

このアルバムは、ネット発の音楽とCDで音楽を聴く層をつなぐことを志向した作品だった。
動画共有サイトを中心にしてきた活動から、EDM以降のポップスへ軸を移していく。
([出典: mikiki](https://mikiki.tokyo.jp/articles/-/12560))

- **2017-02-26** Zepp Tokyo「テンカイ ノ コウシキ」

そして2017年8月、REOLは**発展的解散**を発表する。
行き詰まって畳んだのではなく、次の形へ進むための区切りだった。
([出典: 音楽ナタリー](https://natalie.mu/music/news/243151) /
[『虚構集』オフィシャルインタビュー](http://www.jvcmusic.co.jp/reol/interview/))

- **2017-10-20 / 10-22** REOL LAST LIVE「終楽章」(Zepp Namba / 豊洲PIT)

> ユニット名を得てから終楽章まで、およそ1年半。
> この時点で、ライブで演奏された曲は40曲、公演は19回を数えていた。

### 第3章 — Reol(2018–):ひとりで引き受ける

2018年、**Reol**名義でソロとして再スタートする。

ここで変わったのは表記だけではない。
広告塔としての歌い手ではなく、**作詞作曲を自分で手がけ、クリエイティブとして独り立ちする**——
それがソロ活動の出発点だった。
([出典: 『虚構集』オフィシャルインタビュー](http://www.jvcmusic.co.jp/reol/interview/))

#### 虚構を壊す(2018)

- **2018-01-09「平面鏡」** — ソロ初の配信シングル
- **2018-03-14『虚構集』** — ソロ初のミニアルバム

『虚構集』は、ユニットが終わった直後の不安定な時期に作られている。
リアルとバーチャル、フィクションとノンフィクションの狭間で揺れる感覚がテーマにあり、
**自分自身の虚像を壊すこと**が主題として置かれた。
([出典: 『虚構集』オフィシャルインタビュー](http://www.jvcmusic.co.jp/reol/interview/))

- **2018-10-17『事実上』** — ソロ初のフルアルバム

『虚構集』の時点では、まだユニットが続いていた未来を想像してしまう状態だった。
『事実上』を作る過程で、ようやくソロのアーティストとしての自分を受け入れられたという。
またこの時期、**自分がやりたいのはサブカルチャーではない**という自覚のもと、
メインストリームを意識して間口を広げる方向へ舵を切っている。
([出典: mikiki](https://mikiki.tokyo.jp/articles/-/19466))

#### 塔を建てる(2019–2020)

- **2019-03-20『文明EP』** — アルバムへ向かう途中段階としてのEP
- **2020-01-22『金字塔』**

『文明EP』とそれに続くツアーは、すべて『金字塔』への布石として位置づけられていた。
文明のあとに人は塔を建てる——という発想からタイトルが決まっている。
ツアーで各地に旗を立てる演出は、自分の音楽を核として広げていくことの比喩だった。
([出典: Real Sound](https://realsound.jp/2020/01/post-489912.html))

#### 交差点に出る(2020–2022)

- **2020-07-29「第六感」**

「第六感」は、J-POPとしてのメロディのキャッチーさへ舵を切る起点になった曲で、
配信後の反響がその後の方向性を決めた。
またこの時期から、他アーティストとのコラボレーションが始まる。
受け手として影響を受けてきた立場から、**今度は自分が発信する側へ**という
意識の転換も語られている。
([出典: Real Sound](https://realsound.jp/2021/12/post-924574.html))

- **2021-12-15『第六感』**(ミニアルバム)
- **2022-11-16「COLORED DISC」** — 初のシングル

#### 箱を開ける、そして武道館(2023–2024)

- **2023-10-18『BLACK BOX』**
- **2024-08-17 日本武道館「No title」** — 初の武道館ワンマン

武道館は、活動の10年を総括する場になった。
この日、一夜限りでREOLが復活している。
([出典: 音楽ナタリー](https://natalie.mu/music/news/587038))

> 武道館の時点で、開催済み公演は120回、のべ演奏は1,350回に達していた。

#### 全部切って、次へ(2025–)

- **2025-11-09 横浜アリーナ「無題」**
- **2025-11-09『美辞学 (Rhetoric)』**

『BLACK BOX』のあと、燃え尽きに近い感覚があったという。
もしReolを締めくくるとしたら——という問いから生まれた曲が起点となり、
アルバム『美辞学』へと展開していった。
本人はこれを**原点回帰**と位置づける。
ニコニコ動画の頃に持っていた、アルバムを作りたいという初期衝動に立ち返る、という意味だ。
横浜アリーナでは髪を切る演出があり、次章の開始が示された。
([出典: ENCOUNT](https://encount.press/archives/928766/))

- **2026-03-14 〜 07-26 ワンマンツアー「美辞学」**(全24公演/日本ファイナルは07-10、その後ソウル・台北)
- **2026-07-11「COCOON」**

2026年は**リスタート**の年として位置づけられている。

## 6. 根拠トレース(レビュー用)

### 6-0. この表で検証できること・できないこと

**⚠️ 重要な前提: 元記事の本文は読んでいない。**

記事取得は要約を返す仕組みを経由しており、**受け取ったのは記事本文ではなく機械要約**。
したがって:

- **逐語引用は提示できない**(逐語性が保証できないため、提示すると「原文を確認した」という
  誤った安心感を与えてしまう)
- よってこの表は「引用箇所」ではなく「**どの主張が、どの出典の、どの話題に対応するか**」を示す
- レビューは**出典リンクを開いて、下表の「出典中の該当トピック」と突き合わせる**形でお願いしたい

**また、本リポジトリは公開GitHubリポジトリ**(`github.com/twilightdve/reol`)。
`plan/` 配下も公開されるため、**記事本文の貼り付けは行わない**(それ自体が転載になる)。

### 6-1. 検証状況の凡例

| 記号 | 意味 |
|---|---|
| ✅ | サイト内データから機械的に算出。確実 |
| 📄 | インタビュー要約経由。事実の方向は確かだが**原文未確認** |
| ⚠️ | **二次情報かつ単一ソース。一次情報での裏取り推奨** |

## 7. 実装メモ(承認後に着手する内容)

1. `src/constants/artist.ts` の `ACTIVITY_START_YEAR` / `activityYears()` を本文に接続
2. `welcome.tsx` の `ERAS`(4分割)を**3章(名義)構成**に置き換え
3. 章の配色は既存の `bx-*` CSS変数の範囲で切り替える(ライト/ダーク両対応を維持)
4. スクロール演出は `IntersectionObserver`。`useReducedMotion` で無効化パスを用意
5. データ挿入はビルド時に `timemachine.json` / discography から注入(原稿に直書きしない)
6. MV埋め込みはファサード方式(サムネイル+再生ボタン)を踏襲
7. 本文はSSRのHTMLに含める(演出のみクライアント制御)

### 既存ページとの関係

`/welcome/` を**置き換える**か、`/story/` 等として**別ページで新設**するかは要判断。

- 置き換え: 導線が1本化される。ただし現行の「まずはこの曲から」の即効性は薄れる
- 新設: 現行の入口機能を保てるが、HOMEの導線が1枚増える

> **推奨は置き換え**。案Dの主旨が「`/welcome/` を物語に再構成する」ことであり、
> 曲リスト部分は第3章の節目カードと着地セクションに吸収できるため。

## 8. 要監修・未確定の論点

1. **語り口** — 現ドラフトは短文・体言止め主体の硬めの文体。サイト全体のトーンに合うか
2. **第1章の扱い** — れをる期は本人が意図的に情報を出していなかった時期。
   どこまで踏み込んで書くかは方針判断が必要
3. **2014年『No title』とメンバー構成の裏取り** — 「のちのREOLの3人が2014年時点で揃っていた」
   「REOL結成は2016年3月」は現状Wikipedia由来。**公式プロフィール等の一次情報で再確認したい**。
   物語上は最も効く事実なので、裏取りが取れない場合は表現を弱める(例:「2014年に3人での
   自主制作盤がある」に留める)
4. **章タイトル** — 「声だけが、そこにあった」等はドラフト。より良い言い回しがあれば差し替え
5. **ページタイトル** — 「スクロールで読む{活動年数}年」は元プランの仮題。確定させたい
6. **配色設計** — 章ごとの配色変化は、ライトモードでも成立する範囲に収める必要がある
