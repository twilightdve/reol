# 33. 読みものの分類: シリーズ+タグ

## 決定(2026-10-10 ユーザー)

- 「読みものという括りにするなら、楽曲記事以外の記事も今後作ると思うのでタグ付けしてタグで絞り込むか、シリーズという括りを作るかしたい」→ **シリーズ+タグ**の両方にする。
- 楽曲記事のシリーズ名は **「曲を読む」**(slug `kyoku-wo-yomu`)。
- 参考にした既存の仕組み: 美辞学ナビの読みもの(`src/data/articles/`)は、1記事に1つの「カテゴリ」と複数の「タグ」を持つ。

## 仕組み

| 項目 | 内容 |
| --- | --- |
| シリーズ | 1記事に1つ(必須)。登録表は `src/utils/songArticles/series.ts` の `ARTICLE_SERIES`(名前・説明・表示順)。楽曲記事(kind: song)は「曲を読む」 |
| タグ | 1記事に複数(任意)。楽曲記事はサイトの確認済みデータから自動で付ける: 初出の作品名、初出の年(「2015年」)。`editorial.json` の `tags` で足せる。曲名はタグにしない(2026-10-10 ユーザー決定) |
| 一覧 `/articles/` | シリーズごとに分けて新着順。上に「タグで絞り込む」(記事数の多い順)。`?tag=<タグ>` で絞り込む。静的HTMLは全件で、JSが動いた後に絞り込む(JSなしでも全件を読める) |
| シリーズのページ `/articles/series/<slug>/` | 同じテンプレートで、そのシリーズだけ。記事が1件以上あるシリーズだけ作る |
| 記事ページ | 記事別デザインの下に、サイト共通の配色で「シリーズ」と「タグ」の帯(`ArticleTaxonomy`)。シリーズのページ・タグで絞り込んだ一覧へ進める |
| 構造化データ | Article の keywords にタグ |

## 確認(2026-10-10)

- WebKit(iPhone 15): 一覧・`?tag=極彩色`(1件に絞り込み)・シリーズのページ・記事末尾の帯が表示され、はみ出しなし。
- 単体テスト 67件合格(分類の4件を追加)。

## 未決・相談

- 曲名のタグ → 「曲名タグは外して、作品と年だけにして」(2026-10-10 ユーザー)。外した。3記事のタグは Boy『Boy』・2021年、No title『No title-』・2014年、MONSTER『極彩色』・2015年。Boy の「#Boy」は初出の配信シングル『Boy』(作品)のタグ。
- `/articles/` の説明文は仮(Claude が書いた1文)。シリーズ「曲を読む」の説明は、これまでの一覧の説明文をそのまま使った。
- 美辞学ナビの読みもの(4本)を、別のシリーズとしてこの一覧に合流させるかは未決(bijigaku-navi 本体の扱いも未決)。
- 記事別デザインのパンくず(HOME / 読みもの / 記事)にシリーズを挟むかは未対応。

## 2026-10-11 の変更

- 「読みもの一覧のタグで絞り込むは不要になった」→ 一覧の上の「タグで絞り込む」ボタン群を外した。記事のタグのリンク(一覧の各記事・記事末尾の帯)から `?tag=` で来た時だけ、「#タグ の記事 N件・すべて表示」の一行を出して絞り込む。`/articles/` の説明文(仮)から「タグで絞り込んで読める」を外した。
- 「表紙のプレビュー(未公開)という表示は必要ないのでは？」→ 各記事の表紙・共通テンプレート・一覧の「プレビュー(未公開)」の表示を外した(プレビューのページは引き続き noindex)。
- 「白夜は全然未完成なので表示しないで」→ `status: "draft"` の記事はプレビューにも出さないことにし(`load.ts`、テスト追加)、白夜の editorial.json を draft にした。取込し直しても editorial.json は上書きされないので draft のまま。
- 「読みもの一覧の導線をHOMEのわかりやすい場所に追加して」→ HOME の EXPLORE(主要セクションの大タイル)のすぐ下に「READING 読みもの」の欄を置いた。新しい楽曲記事を最大3本(曲名と題のカード)と「読みもの一覧へ →」。
  - 記事の情報は gatsby-node の onCreatePage で HOME(/)の pageContext に渡す(`homeArticles`。公開日時 → 作成日の新しい順)。通常ビルドでは公開済みの記事だけ、プレビューでは確認中も含む(draft は除く)。
  - **記事が0本なら欄ごと出さない**(本番で公開記事が無い間は /articles/ 自体が作られないため、リンク切れにしない)。
  - 読みものは日本語だけなので、日本語の HOME にだけ出す(言語別の HOME では空)。
  - WebKit(iPhone 15、PC 1280px)ではみ出しなし。
