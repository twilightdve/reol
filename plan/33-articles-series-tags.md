# 33. 読みものの分類: シリーズ+タグ

## 決定(2026-10-10 ユーザー)

- 「読みものという括りにするなら、楽曲記事以外の記事も今後作ると思うのでタグ付けしてタグで絞り込むか、シリーズという括りを作るかしたい」→ **シリーズ+タグ**の両方にする。
- 楽曲記事のシリーズ名は **「曲を読む」**(slug `kyoku-wo-yomu`)。
- 参考にした既存の仕組み: 美辞学ナビの読みもの(`src/data/articles/`)は、1記事に1つの「カテゴリ」と複数の「タグ」を持つ。

## 仕組み

| 項目 | 内容 |
| --- | --- |
| シリーズ | 1記事に1つ(必須)。登録表は `src/utils/songArticles/series.ts` の `ARTICLE_SERIES`(名前・説明・表示順)。楽曲記事(kind: song)は「曲を読む」 |
| タグ | 1記事に複数(任意)。楽曲記事はサイトの確認済みデータから自動で付ける: 初出の作品名、初出の年(「2015年」)。`editorial.json` の `tags` で足せる。曲名はタグにしない(2026-10-10 ユーザー決定) |
| 一覧 `/articles/` | シリーズごとに分けて新着順。上に「タグで絞り込む」(記事数の多い順)。`?tag=<タグ>` で絞り込む。静的HTMLは全件で、JSが動いた後に絞り込む(JSなしでも全件を読める) |
| シリーズのページ `/articles/series/<slug>/` | 同じテンプレートで、そのシリーズだけ。記事が1件以上あるシリーズだけ作る |
| 記事ページ | 記事別デザインの下に、サイト共通の配色で「シリーズ」と「タグ」の帯(`ArticleTaxonomy`)。シリーズのページ・タグで絞り込んだ一覧へ進める |
| 構造化データ | Article の keywords にタグ |

## 確認(2026-10-10)

- WebKit(iPhone 15): 一覧・`?tag=極彩色`(1件に絞り込み)・シリーズのページ・記事末尾の帯が表示され、はみ出しなし。
- 単体テスト 67件合格(分類の4件を追加)。

## 未決・相談

- 曲名のタグ → 「曲名タグは外して、作品と年だけにして」(2026-10-10 ユーザー)。外した。3記事のタグは Boy『Boy』・2021年、No title『No title-』・2014年、MONSTER『極彩色』・2015年。Boy の「#Boy」は初出の配信シングル『Boy』(作品)のタグ。
- `/articles/` の説明文は仮(Claude が書いた1文)。シリーズ「曲を読む」の説明は、これまでの一覧の説明文をそのまま使った。
- 美辞学ナビの読みもの(4本)を、別のシリーズとしてこの一覧に合流させるかは未決(bijigaku-navi 本体の扱いも未決)。
- 記事別デザインのパンくず(HOME / 読みもの / 記事)にシリーズを挟むかは未対応。

## 2026-10-11 の変更

- 「読みもの一覧のタグで絞り込むは不要になった」→ 一覧の上の「タグで絞り込む」ボタン群を外した。記事のタグのリンク(一覧の各記事・記事末尾の帯)から `?tag=` で来た時だけ、「#タグ の記事 N件・すべて表示」の一行を出して絞り込む。`/articles/` の説明文(仮)から「タグで絞り込んで読める」を外した。
- 「表紙のプレビュー(未公開)という表示は必要ないのでは？」→ 各記事の表紙・共通テンプレート・一覧の「プレビュー(未公開)」の表示を外した(プレビューのページは引き続き noindex)。
- 「白夜は全然未完成なので表示しないで」→ `status: "draft"` の記事はプレビューにも出さないことにし(`load.ts`、テスト追加)、白夜の editorial.json を draft にした。取込し直しても editorial.json は上書きされないので draft のまま。
- 「読みもの一覧の導線をHOMEのわかりやすい場所に追加して」→ HOME の EXPLORE(主要セクションの大タイル)のすぐ下に「READING 読みもの」の欄を置いた。新しい楽曲記事を最大3本(曲名と題のカード)と「読みもの一覧へ →」。
  - 記事の情報は gatsby-node の onCreatePage で HOME(/)の pageContext に渡す(`homeArticles`。公開日時 → 作成日の新しい順)。通常ビルドでは公開済みの記事だけ、プレビューでは確認中も含む(draft は除く)。
  - **記事が0本なら欄ごと出さない**(本番で公開記事が無い間は /articles/ 自体が作られないため、リンク切れにしない)。
  - 読みものは日本語だけなので、日本語の HOME にだけ出す(言語別の HOME では空)。
  - WebKit(iPhone 15、PC 1280px)ではみ出しなし。
- 「HOMEにはNo title, 1LDK, Boyの順番で表示してください」(2026-10-11)→ HOME の読みもの欄は新しい順ではなく、`HOME_ARTICLE_IDS`(series.ts)の記事をその順に出す(No title → 1LDK → Boy)。未公開・draft の記事は飛ばし、1本も無ければ欄を出さない。

## 記事末尾: いいね・その他の記事(2026-10-11)

- 記事別デザインの下に `ArticleEnd`(サイト共通の配色)を置く。順は いいね → その他の記事(最大3本)→ シリーズとタグ。
- 見出しは「関連記事」ではなく「その他の記事」(ユーザー指定: 何が関連か分かりにくく、記事数も少ないため)。並びは `pickRelatedArticles`(`relatedArticleIds` 優先 → 共通タグ・同シリーズ → 作成日の新しい順)。
- いいねはログイン不要で誰でも押せる(ユーザー決定)。ブラウザごとの無作為な ID(localStorage)で1記事1回、取り消し可。
  DB は `supabase/features/supabase-article-likes.sql`(テーブル直接アクセス不可、RPC `get_article_likes` / `set_article_like` のみ)。
  ID を作り直せば何度でも押せるので、数は目安(厳密な不正防止はしない)。DB に関数が無い・通信できない時はボタンを押せなくし、短い案内を出す。

## 記事ごとの OGP 画像(2026-10-12)

- 表紙のデザインをそのまま撮って OGP 画像(1200x630)にする(ユーザー希望「表紙風のデザインをOGP画像に」)。
- `npm run articles:og`(開発サーバー起動中に実行。`-- <slug>` で1本だけ)→ `static/articles-og/<slug>.jpg` に書き出し、コミットする。ビルドの中では撮らない。
- 撮るのは各デザインの `data-og-cover` を付けた要素だけ。サイトの枠・パンくず・リンクは隠し、右下に「!Legit — Reol 非公式ファンサイト」を入れる。
- MVのサムネイル・ジャケットなど公式の画像は焼き込まない(サイトは公式の埋め込み・リンクだけを使う方針のため)。外して空いた所は記事ごとの調整(スクリプトの `PER_ARTICLE_CSS`)で詰める。
- プレビューのサーバーで未公開の原稿が出ていても撮らないよう、表紙の題名が公開中の題名と違えば止める。
- ページの `og:image` には、全ページ共通で SEO 部品がビルド時刻 `?t=<Unix秒>` を付ける(2026-10-12 から。それまでは画像のハッシュ `?v=`)。撮り直した画像はデプロイ後に SNS が読み直す。
- 公開中の記事に画像が無いと、デプロイ前チェック(`check-deploy-ready.ts`)で止まる。表紙のデザインや題名を変えたら撮り直す(古い画像のままでもチェックは通るので注意)。

## 一覧のいいね数と並べ替え(2026-10-12)

- ユーザー「読み物一覧ページで記事のいいね数を表示したりソートできるようにしたい」。
- 各記事の作成日の横に「♡ 数」。一覧の上に「新着順」(既定。静的HTMLと同じ)/「いいねが多い順」(同数は新着順)の切り替え。選んだ並びは `?sort=likes` で URL に残る(`?tag=` と併用可)。
- いいね数は JS が動いた後に、全記事分をまとめて1回で読む(RPC `get_article_like_counts(p_article_ids text[])`、`supabase/features/supabase-article-like-counts.sql`。一度に200本まで。数だけを返す)。ユーザーが SQL Editor で適用済み。
  読めない時は数を出さず、いいね順は選べない(一覧は新着順のまま表示)。
- 選択中のボタンは `bg-bx-blue` に `text-bx-bg`(白だとダークテーマでコントラスト 3.25 で不足。地の色でダーク 6.03・ライト 8.03)。

## 一覧のアルバム絞り込み(2026-10-13)

- ユーザー「記事一覧でアルバム単位で絞り込みできるようにしたい」。
- 一覧の記事データに初出の作品(`album`: 作品名・発売日。`songFacts.releases[0]`)を持たせ、一覧の上に「アルバム」の選択欄(すべて/作品名(年)— 本数。発売日の古い順)。選ぶと `?album=<作品名>` で URL に残り、`?tag=`・`?sort=` と併用できる。「解除」で全件に戻る。
- 静的 HTML は全件で、JS が動いた後に絞り込む。作品が1つしか無い時は選択欄を出さない。
- タグ(`#作品名`)でも同じ作品の記事に絞れるが、選択欄は作品をまとめて選べるようにするためのもの(タグの絞り込みボタン群は 2026-10-11 に外したまま)。
